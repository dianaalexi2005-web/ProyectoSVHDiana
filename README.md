# Museo Alien

Bienvenido al repositorio del **Museo Alien**, un espacio dedicado a la divulgación de misterios extraterrestres.

## 🚀 Descripción
En esta página descubrirás diferentes tipos de alienígenas y sus estimados planetas de origen. 

## 🗺️ Navegación del Sitio
El sitio web cuenta con las siguientes secciones principales:
* **Inicio:** Pantalla principal de bienvenida.
* **Aliens:** Información detallada sobre distintas especies extraterrestres.
* **Planetas:** Detalles sobre los mundos y entornos donde habitan.
* **Galería:** Contenido visual e imágenes astronómicas y alienígenas.
* **Contacto:** Formulario y vías de comunicación.
